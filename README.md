# Today App                                                                 
                                                                             
  A portmanteau of "To-do" and "Today".
  A quiet, focused todo app for getting through the day.         
   
  ## Features                                                                   
  
  - Focus mode that surfaces your single most important task at the top while you work and erases everything else so you're not overwhelmed 
  - Automatic Eisenhower Matrix + deadline sorting so you don't spend another precious 10 minutes debating what to do next
  - Satisfying task clearing and optional reflections for a heightened sense of achievement                       
  - Warm, minimal aesthetic designed to stay out of your way
  - Stripped-down interface with no clutter or menus  

  ## Requirements                                                               
  
  - Node.js                                                                     
  - npm    

  ## Install

  ```bash
  npm install
  ```

  ## Run

  ```bash
  npm start
  ```

  ## Stack

  - [Electron](https://www.electronjs.org/)                                     
  - Vanilla HTML/CSS/JS (`today-todo.html`)
                                                                                
  ## Data  

  App data stored at `~/.today-app-data`.
